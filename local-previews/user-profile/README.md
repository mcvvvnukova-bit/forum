# Локальный профиль пользователя АСТ Форум

Локальный адрес: http://127.0.0.1:5190/

Задача: [PROJ-150](https://roadmap.astforum.ru/work_packages/PROJ-150).

```sh
npm ci
npm run dev
```

Команды выполняются из `local-previews/user-profile`. Сервер привязан к 127.0.0.1:5190; при занятом порте останавливается с ошибкой. Другие приложения не изменяются.

## Возможности

Шесть групп только для просмотра: личные данные, документ, адреса, ИНН, контакты, СНИЛС. Раскрываемые дополнительные сведения пакета Professional: работа и образование, самозанятость, водительское удостоверение, загранпаспорт, СТС, прежний паспорт и ФИО, другие адреса, семейное положение. Боковая навигация ведёт к разделам; на мобильном экране она открывается в Primer Dialog. Действие «Как изменить данные» объясняет изменение профиля в Сбере.

Все значения в `src/fixtures.ts` вымышленные. Получение реального userinfo, OAuth, хранение персональных данных и серверная публикация отсутствуют. Панель «Состояния макета» ниже страницы переключает наполненный/частичный профиль, ограниченный набор scope, загрузку и ошибку. Повтор после ошибки возвращает демонстрационный пример.

## Контракт данных

`src/profile.ts` описывает необязательные поля ответа Сбер ID и `buildProfileSections(profile, approvedScopes)`. Максимальный пакет Professional включает Light/Standart, но партнёру может быть согласован меньший набор. Поле вне approvedScopes выводится как «Не запрошено», даже если оно присутствует во входном объекте. Разрешённое отсутствующее поле — «Не передано». `false` для самозанятости — «Нет». Технический `sub` и коды метаданных не выводятся. ISO-даты переводятся в русский формат; невозможная дата не подменяется нормализованной. При отсутствии maindoc используется разрешённый priority_doc; неизвестный/отсутствующий тип не называется паспортом РФ.

Источники проверены 5 октября 2026 года:

- [Состав пакетов Сбер ID](https://developers.sber.ru/docs/ru/sberid/service/scopes).
- [Контракт userinfo](https://developers.sber.ru/docs/ru/sberid/service/reqdescription/datareq/overview).
- [Компоненты Primer](https://primer.style/product/components/).

## Дизайн

Только Primer React, Primitives и Octicons; Light-only. В Figma проверена библиотека Primer Web и прочитаны переменные фирменного стиля. Полная цепочка collection Forum / Light → семантическая роль → Primer не подтверждена; используется временная стандартная тема Primer Light. Forum-цвета, шрифты и focus-цвета не выведены из скриншота и не перенесены. Логотип скопирован из существующего локального приложения проекта без изменения изображения.
