# PROJ-160: Выход в шапке кабинета

По прямому запросу владельца кнопка выхода на `/cabinet/` размещается справа от имени пользователя в шапке. Используется Primer IconButton с Octicon SignOutIcon, без видимого текста, с доступным названием «Выйти». Нижняя строка с разделителем, копирайтом, «Физлицо» и ссылкой «На главную» удаляется целиком. Общая шапка даёт такое же поведение на `/cabinet/work/`.

Существующий обработчик POST `/api/auth/logout`, блокировка повторного нажатия, предупреждение при ошибке и возврат на начало главной сохраняются. Изменения применяются только при переданном `account`; отдельный демонстрационный `/profile/` сохраняет свой копирайт. На ширине 320px логотип уменьшается, имя может переноситься, иконка остаётся доступной.

Основа — опубликованный dev commit `e6a910c4aa7f5795a1c178a47c64a1dc5aea9875`. Публикация затрагивает только dev web artifact через существующий атомарный publisher. API, база данных, gateway, production и независимый preview не меняются.
