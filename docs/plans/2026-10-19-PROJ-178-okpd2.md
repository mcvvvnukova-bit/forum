# PROJ-178 — ОКПД2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task, with one whole-branch review before dev publication.

**Goal:** Загрузить официальный ОКПД2, обновлять по субботам в 01:00 МСК и показывать администратору поиск по коду и названию на dev.

**Architecture:** Отдельная интеграция Росстата: ограниченный Python-адаптер распаковывает две части DOCX и выдает проверенный JSON; Node/pg-boss управляет очередью и транзакционной публикацией в отдельные таблицы ОКПД2. API и общий Primer-компонент справочника повторяют контракт ОКВЭД2; существующий FNS worker продолжает работать самостоятельно.

**Tech Stack:** Node 24, TypeScript, PostgreSQL, pg-boss 12.37.1, Python 3 stdlib, libarchive bsdtar, Nest/Fastify, React 19, Primer.

**Spec:** https://docs.astforum.ru/doc/adm020201-integraciya-s-sistemoj-istochnikom-nJBdiTMnBK — раздел «ОКПД2: интеграция и страница справочника — PROJ-178 (19.10.2026)».
