# Пакет сделки

## Назначение

После выбора победителя платформа формирует пакет сделки и раскрывает контакты по правилам модуля [M08 — выбора победителя](M08-winner-selection.md). Пакет сделки — конечная точка транзакционного процесса MVP.

## Граница MVP

В MVP нет подписания договоров, ЭДО, платежей, закрывающих документов и других глубоких транзакционных сценариев. Платформа помогает распределить заказ и выбрать предложение, но не заменяет договорный или платёжный контур.

После фактического исполнения заказчик вручную подтверждает состоявшуюся сделку. Только после этого доступен процесс [M10 — отзывов](M10-reviews.md).
