# Запись на демо Платформы

## Назначение

Модуль записи на демо Платформы

## Доступные функциональные возможности
- Синхронизация c 1с битрикс 24 для обработки входящих лидов и доведения их до регистрации в системе
- trueconf или яндекс.телемост для создания ссылок на ВКС для демо
- Демо для физ лиц - 30 минут слот
- Демо для юр лиц - 60 минут слот
- Подключить рассыльщик писем (Unisender): письмо о записи на демо, уведомление за час, уведомление за 15 минут до встречи на демо.

Посмотреть, возможно уже есть готовые модули для сайта от битрикса.

Битрикс развернут на локальном сервере.
