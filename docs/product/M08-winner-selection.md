# Выбор победителя

## Назначение

Заказчик просматривает структурированные предложения по лоту и выбирает одного или нескольких победителей. Частичное исполнение доступно только если оно было разрешено при создании лота.

## Правила выбора

По умолчанию предложения сортируются по дате поступления, новые показываются сверху; заказчик может изменить порядок сортировки. Умное ранжирование по цене, срокам и документам отложено в бэклог. Выбор можно сделать до дедлайна: он закрывает сбор предложений по лоту.

## Контакты

До выбора победителя контакты исполнителей скрыты. После выбора заказчик видит контакты всех исполнителей, откликнувшихся на соответствующий лот. Исполнители не видят контакты друг друга. Исполнитель видит контакты заказчика только если выбран победителем; при нескольких победителях контакты заказчика открываются всем выбранным.

После выбора формируется [M09 — пакет сделки](M09-deal-package.md).
