# Аккредитованные ЭТП

> [!Примечание]
> Статус «Аккредитация» означает включение оператора в [перечень, утверждённый распоряжением Правительства РФ № 1447-р](https://publication.pravo.gov.ru/Document/View/0001201807170009), для процедур по 44-ФЗ и закупок у субъектов МСП по 223-ФЗ. Отсутствие в перечне не запрещает площадке проводить коммерческие и иные корпоративные закупки, включая отдельные процедуры по 223-ФЗ.
