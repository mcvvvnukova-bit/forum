## Термины

- ЭЦП (ЭП) - электронно-цифровая подпись:
	- НЭП - неквалифицированная электронная подпись
	- ПЭП - простая электронная подпись
	- УКЭП - усиленная квалифицированная электронная подпись
- МЧД - машинно-читаемая доверенность (выдается на сотрудника (не директора) компании для совершения операций).
- УЦ - удостоверяющий центр, выпускающий ЭЦП.
- ИП - индивидуальный предприниматель.
- ВИС - внешняя информационная система по отношению к сервисам ЕПГУ

## НПА, которые регулируют выпуск ЭЦП

- [Федеральный закон от 06.04.2011 N 63-ФЗ (ред. от 31.07.2025) "Об электронной подписи"](https://www.consultant.ru/document/cons_doc_LAW_112701/)
- [Федеральный закон от 27.12.2019 № 476-ФЗ](http://publication.pravo.gov.ru/document/view/0001201912280086) - поправка в 63-ФЗ, согласно которой выпускать ЭЦП для юридических лиц и ИП может только ФНС
- [Федеральный закон от от 04.08.2026 N 315-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_541004/3d0cac60971a511280cbba229d9b6329c07731f7/#dst100024) - принят и вступает в действие с ==01.09.2027г.==

Госключ - не является УЦ и сам по себе не выдает ЭЦП. Он является прослойкой между клиентом (любым) и соответствующим УЦ,
Справочная информация:
- https://www.gosuslugi.ru/help/faq/state_key/55501
- https://partners.gosuslugi.ru/catalog/goskey - информация об интеграции с Госключом. Возможны 2 вида интеграции с Госключом:
	- СМЭВ (фоив, роив и коммерческие организации, если они перечислены в соответствующем НПА)
	- API (для всех, кто не попадает под СМЭВ, в т.ч. коммерческие организации)
- Интеграция с Госключом возможна только после:
	- получения ЕСИА для ВИС коммерческой организации
	- наличия оборудования или ПО, обеспечивающее реализацию протокола SSL/TLS (1.2) c ГОСТ Р 34.12-2015 (п. 3.5 Регламента API Госуслуг) или подключения к [ЗСПД СВОКС](https://digital.gov.ru/documents/opisanie-tehnicheskogo-resheniya-svoks) (аналог СМЭВ для взаимодействия с коммерческими организациями) (информация получена из формы заявки на подключение к Госключу)

## Важный нюанс: ЭЦП + сертификат ЭТП

Сама по себе ЭЦП от УЦ (Тензор, Контур, ФНС) — это **базовый сертификат**. Для работы на конкретной площадке к нему нужно добавить **сертификат ЭТП** — это доп. сертификат, который «привязывает» подпись к конкретной площадке.

- **Одноплощадочная ЭЦП** = базовая подпись + сертификат 1 площадки
- **Универсальная ЭЦП** = базовая подпись + сертификаты **всех 24+ площадок**
