# Главная страница Системы

## Назначение

Лендинг объясняет ценность платформы АСТ Форум для заказчиков и исполнителей. Цели:
- пользователь регистрируется на платформе (основная цель)
- пользователь записывается на демо платформы (дополнительная цель)
- пользователь входит в систему (вторичная цель)

Макеты:
- общий лендинг - https://www.figma.com/design/WT2IPB0eHD9ULCPENEktwp/%D0%9C%D0%B0%D0%BA%D0%B5%D1%82%D1%8B-2.0?node-id=7-3940&t=0PXm89MH3CyGbp1J-4
- для юридических лиц и ИП (для целевого трафика привлечения компаний строительной отрасли)
- для физических лиц (для целевого трафика привлечения сотрудников на проекты)

## Доступные разделы

- Header (панель навигации):
	- логотип
	- меню перехода по разделам Landing page;
	- кнопка "Войти" [M02 — Регистрация/авторизация](M.02.00.Registration-and-authorization.md)
	- кнопка "Регистрации" [M02 — Регистрация/авторизация](M.02.00.Registration-and-authorization.md)
- Hero-блок (первый экран);
	- ==Заголовок:==
	- ==Подзаголовок:==
	- Кнопки призыва к действию
		- Начать работу
		- Записаться на демо
	- ==Картинка (скриншот из интерфейса системы)
- Блок "Для кого":
	- Юридические лица и индивидуальные предприниматели
		- Заказчик
		- Исполнитель:
			- Поставщики материалов
			- Исполнители работ и услуг
	- Физические лица:
		- Найм в штат
		- ГПХ
		- Самозанятые
- Блок "Как это работает для Заказчика":
	- Шаг 1. Регистрация
	- Шаг 2. Публикация сметы или отдельного заказа
	- Шаг 3. Сбор предложений
	- Шаг 4. Выбор победителей
	- Шаг 5. Сопровождение сделки
	- Шаг 6. Завершение проекта
- Блок "Как это работает для Исполнителя":
	- Шаг 1. Регистрация
	- Шаг 2. Получение профильных заказов
	- Шаг 3. Отклики
	- Шаг 4. Исполнение заказа
	- Шаг 5. Сопровождение сделки
	- Шаг 6. Завершение проекта
- Блок "Запись на демо":
	- Заголовок: приглашение на демонстрацию возможностей платформы
	- Кнопка "Записаться на демо"
	- Календарь доступных слотов (даты и время) для демо
	- Автоматически формируемая ссылка на ВКС в Телемосте
- Блок "Статистика":
	- Количество исполнителей
	- Количество открытых заказов
	- Сумма сделок, руб
- Блок "Нам доверяют" - лого компаний, которые уже пользуются платформой
- Блок "Кейсы":
- Блок "Ответы на часто задаваемые вопросы"
- Footer (подвал):
	- логотип платформы;
	- слоган платформы;
	- Заказчикам
	- Исполнителям
	- Контакты:
		- телефон
		- email
		- ИНН
		- Название организации
	- Согласие на обработку персональных данных
	- Политика конфиденциальности
- Уведомление о куки

Публичных каталогов лотов и исполнителей нет. Сведения о заказах и исполнителях не индексируются и не показываются незарегистрированным пользователям.
