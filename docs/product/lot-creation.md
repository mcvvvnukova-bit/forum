# Создание лотов

## Назначение

Платформа предлагает разбиение заказа на лоты по нормализованным строкам сметы. Заказчик редактирует предложенные лоты, разрешает или запрещает частичное исполнение и отправляет лоты на модерацию.

## Обязательное раскрытие данных

Исполнитель видит только опубликованный лот, а не весь проект, объект, заказ-смету или профиль заказчика. Платформа определяет минимальный объём данных, необходимый для подготовки предложения. Заказчик может редактировать лот, но не может удалить этот обязательный минимум.

## Модерация и жизненный цикл

Модератор проверяет лот до публикации. При отклонении он указывает причину из справочника и комментарий. После одобрения лот публикуется и становится доступен только подходящим исполнителям. Если предложений нет, заказчик может доработать лот и повторно направить его на модерацию либо снять лот.

Видимость опубликованного лота определяет модуль [рассылки лотов](lot-distribution.md).
