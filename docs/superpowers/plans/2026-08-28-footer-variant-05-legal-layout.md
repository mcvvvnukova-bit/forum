# Footer Variant 05 Legal Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перекомпоновать только Figma-узел `484:87`: сверху слева логотип и регистрационная строка, ниже разделитель, затем copyright слева и четыре юридические ссылки вертикально справа.

**Architecture:** Существующий exploration-вариант остаётся светлым вертикальным Auto Layout шириной 1248 px. Работа выполняется внутри текущей структуры Primer Footer и связанных Primer Link без detach; новые контейнеры допускаются только как нейтральные Auto Layout-обёртки внутри `484:87`. Действующий подвал лендинга `506:261` используется как неизменяемый контрольный узел.

**Tech Stack:** Figma MCP `use_figma`, Figma MCP `get_screenshot`, Primer Web (Community), Figma Variables `Forum / Light`, текстовые стили FORUM.

**Spec:** `docs/superpowers/specs/2026-08-28-footer-variant-05-legal-layout-design.md`
