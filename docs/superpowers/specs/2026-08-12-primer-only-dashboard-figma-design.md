# Экран «Обзор», собранный только из компонентов Primer

## Цель

Создать в Figma рядом с исходным экраном `Desktop / Обзор / Верифицирована` отдельный фрейм с теми же данными и пользовательскими задачами, но с максимально строгим использованием официальной Figma-библиотеки Primer.

## Подтверждённый подход

Выбран вариант 2: максимальная компонентная чистота.

- Корневой технический фрейм экрана — допустимое исключение, необходимое для размещения интерфейса на холсте.
- Фирменный логотип АСТ «Форум» сохраняется как брендовый компонент и является единственным содержательным исключением.
- Все остальные смысловые, интерактивные и компоновочные блоки должны быть экземплярами официальных компонентов Primer.
- Локальные компоненты `Primer / FORUM / ...` не используются.
- Новые локальные компоненты и копии компонентов Primer не создаются.
- Обычные текстовые и графические слои вне официальных компонентов Primer не используются.

## Содержание экрана

Сохраняются данные исходного макета:

- организация `ООО «Стройконтур»`;
- статус `Верифицирована`;
- пользователь `Алексей Смирнов`;
- навигационные разделы кабинета;
- заголовок `Обзор` и его описание;
- действия `Разместить заказ` и `Найти заказы`;
- четыре операционных показателя;
- три записи в блоке `Требует внимания`;
- списки `Мои заказы` и `Подходящие заказы`.

## Компонентная архитектура

| Область | Официальная основа Primer |
|---|---|
| Общая раскладка | `PageLayout` и его области `Header`, `Sidebar`, `Content` |
| Верхняя область | официальный компонент или композиционный слот Primer для header; логотип — брендовый экземпляр |
| Боковая навигация | `NavList`, `NavList.Group`, `NavList.Item` |
| Заголовок страницы | `PageHeader`, `PageHeader.TitleArea`, `PageHeader.Title`, `PageHeader.Description`, `PageHeader.Actions` |
| Основные действия | `Button` с официальными вариантами `primary` и `default` |
| Статус организации | `Label` с ближайшей доступной официальной схемой |
| Операционные показатели | `Card` с официальными слотами заголовка, описания и метаданных |
| Блок внимания | `ActionList` и `ActionList.Item` с описанием и trailing action |
| Списки заказов | `ActionList` и `ActionList.Item` |

Если официальная Figma-библиотека не предоставляет компонент из таблицы, соответствующий блок нельзя заменять локальной ручной имитацией. Нужно использовать ближайший официальный компонент Primer либо упростить композицию, сохранив содержание и действие.

## Визуальные ограничения

- Размер нового фрейма: 1440 × 1100 px, как у исходника.
- Новый фрейм размещается рядом с исходным и получает имя `Desktop / Обзор / Primer — strict`.
- Сохраняется иерархия: header, sidebar, main content, показатели, внимание, два списка заказов.
- Визуальный язык определяется официальными компонентами и токенами Primer; точное воспроизведение локальной оранжевой стилизации не требуется.
- Цвета, интервалы, радиусы и типографика берутся из официальных variables/styles Primer. Жёстко заданные визуальные значения допускаются только для размера и положения корневого технического фрейма.
- Шрифт определяется официальными текстовыми стилями Primer, даже если он отличается от Golos Text исходного макета.

## Порядок сборки

1. Проверить Code Connect в рабочем проекте; при отсутствии отметить его как недоступный источник.
2. Проинспектировать компоненты, используемые на существующем экране, и исключить локальные `Primer / FORUM` из повторного использования.
3. Найти подключённую или доступную официальную библиотеку Primer.
4. Собрать карту ключей, вариантов и текстовых свойств необходимых компонентов.
5. Найти официальные Primer variables и text styles.
6. Создать корневой фрейм рядом с исходным.
7. Добавлять официальные экземпляры Primer последовательно по областям экрана.
8. Настраивать содержание через component properties, без detach и без редактирования внутренних слоёв.
9. Провести структурную и визуальную проверку.

## Проверка результата

Результат считается готовым, если:

- новый фрейм существует отдельно от исходного;
- исходный фрейм не изменён;
- логотип АСТ «Форум» сохранён;
- все остальные смысловые элементы являются связанными экземплярами официальной библиотеки Primer;
- отсутствуют экземпляры локальных компонентов `Primer / FORUM`;
- отсутствуют detached instances и созданные вручную аналоги компонентов;
- значения текстов соответствуют исходному экрану;
- нет обрезанного текста, наложений, пустых обязательных областей и плейсхолдеров;
- структура остаётся читаемой при ширине 1440 px;
- итоговый аудит явно перечисляет официальные компоненты и два допустимых исключения: корневой фрейм и брендовый логотип.

## Поведение при недоступности официальной библиотеки

Если библиотека Primer отсутствует среди доступных библиотек Figma или нужные официальные компоненты нельзя импортировать, работа останавливается до изменения холста. В этом случае нельзя подменять требование локальными компонентами; пользователю сообщается конкретное ограничение и список недоступных компонентов.
