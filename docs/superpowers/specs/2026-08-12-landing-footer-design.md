# Дизайн футера лендинга АСТ «Форум»

Дата: 2026-08-12
Статус: согласовано для реализации

## Цель

Заменить текущий локальный футер лендинга на инстанс официального Figma-компонента `Footer` из библиотеки `Primer Web (Community)` и адаптировать его под фирменный стиль АСТ «Форум». Структура и адаптивный паттерн должны оставаться Primer, а типографика, цвета и контент — соответствовать брендбуку и продуктовой спецификации лендинга.

## Исходное состояние

- Футер лендинга находится в узле `101:80` файла Figma `WT2IPB0eHD9ULCPENEktwp`.
- Текущий узел является инстансом локального компонента `Primer / Footer / Standard` с источником `101:71`; источник не является удалённым библиотечным компонентом.
- Визуально футер следует паттерну Primer, но технически не использует официальный библиотечный asset.
- Текст набран `Golos Text`, но локальные текстовые стили FORUM не применены.
- Цвета заданы непосредственно в слоях и не связаны с локальными переменными FORUM.
- Отсутствуют контакты и юридические ссылки, перечисленные в спецификации лендинга.

## Выбранный подход

Использовать компонент-сет `Footer` из `Primer Web (Community)` с ключом `ecbd4c9b2adb690db9fc4baab925ba5c7915b4a9`. Библиотека описывает его как Figma-компонент для макетов, основанный на футере Primer/GitHub. После импорта выбрать наиболее близкий к текущему десктопному футеру вариант и настроить поддерживаемые свойства и overrides без отсоединения инстанса.

Если структура импортированного варианта не позволяет разместить обязательный контент через штатные свойства и вложенные overrides, допускается обернуть инстанс Primer дополнительным auto-layout контейнером для брендового и юридического контента. Сам инстанс Primer должен остаться присоединённым к библиотечному компоненту.

## Структура контента

Футер содержит четыре смысловые группы:

1. Бренд:
   - `АСТ «Форум»`;
   - `Платформа для участников строительства`.
2. Навигация:
   - `О платформе`;
   - `Для заказчиков`;
   - `Для исполнителей`.
3. Контакты:
   - `Контакты`;
   - телефон;
   - email;
   - ИНН;
   - полное название организации.
4. Юридическая строка:
   - `© 2026 АСТ «Форум»`;
   - `Согласие на обработку персональных данных`;
   - `Политика конфиденциальности`.

Фактические телефон, email, ИНН и название организации берутся из уже существующих данных макета или документации. Если достоверных значений в файле нет, в футер не добавляются вымышленные реквизиты: сохраняются только заголовок `Контакты` и существующие подтверждённые данные.

## Типографика

- Название бренда: локальный стиль `FORUM / Heading / Section` — `Unbounded SemiBold`, 16/24.
- Основной текст, навигация и контакты: `FORUM / Body / Regular` — `Golos Text Regular`, 14/20.
- Copyright и юридические ссылки: `FORUM / Body / Small` — `Golos Text Regular`, 12/16.
- Текстовые стили применяются через ссылки на локальные Figma Text Styles, а не через ручной набор параметров.

Такое разделение соответствует брендбуку: `Unbounded` используется как акцидентный шрифт, `Golos Text` — для наборного текста.

## Цвета и токены

Все доступные цвета связываются с локальными переменными коллекции `FORUM / Dashboard Tokens`:

- фон футера: `color/bg/default`;
- основной текст: `color/text/primary`;
- вторичный текст и неакцентные ссылки: `color/text/secondary`;
- разделитель: `color/border/default`;
- акцентные состояния ссылок: `color/text/accent`.

Фирменная основа: `#282828`, `#4A4A4A`, `#FF551A`, белый фон. Новые несистемные цвета не создаются.

## Компоновка

- Десктопный футер занимает ширину внутреннего контейнера лендинга и выравнивается по сетке страницы.
- Верхняя часть строится колонками на auto layout: бренд слева, навигация и контакты справа.
- Нижняя юридическая строка отделяется разделителем и допускает перенос длинных ссылок без наложений.
- Внутренние отступы и интервалы сохраняют шаги, заданные Primer-компонентом; произвольные абсолютные позиции не добавляются.
- Высота футера определяется содержимым. Текущая фиксированная высота 152 px не сохраняется, если полный контент требует больше места.
- Футер не должен выглядеть отдельной «карточкой»: фон совпадает с поверхностью страницы, а иерархия создаётся разделителем и отступами.

## Интерактивность и доступность

- Ссылки имеют различимое акцентное состояние для hover/focus, основанное на `color/text/accent`.
- Контраст основного и вторичного текста на белом фоне должен соответствовать WCAG AA для используемых размеров.
- Длинные юридические формулировки не обрезаются.
- Порядок чтения слоёв: бренд → навигация → контакты → юридическая информация.

## Ограничения

- Не отсоединять библиотечный инстанс Primer без необходимости.
- Не менять остальной лендинг.
- Не создавать дубликаты существующих FORUM-токенов и текстовых стилей.
- Не использовать вымышленные контактные данные или реквизиты.
- Не заменять логотип и фирменные активы вне футера.

## Проверка результата

1. Структурная проверка:
   - футер остаётся `INSTANCE` библиотечного компонента Primer либо содержит такой инстанс как основной структурный элемент;
   - source component входит в импортированный component set с ключом официального asset `ecbd4c9b2adb690db9fc4baab925ba5c7915b4a9`;
   - текстовые слои используют стили FORUM;
   - цвета связаны с переменными FORUM.
2. Визуальная проверка:
   - нет обрезанного текста, наложений и неравномерных интервалов;
   - футер выровнен по контейнеру лендинга;
   - брендовая типографика и цвета визуально соответствуют брендбуку;
   - длинные юридические ссылки читаемы.
3. Контентная проверка:
   - присутствуют все подтверждённые обязательные пункты;
   - отсутствуют вымышленные реквизиты.

## Критерий готовности

Футер визуально интегрирован в лендинг, основан на официальном Figma-компоненте Primer, использует брендовые стили `Unbounded` и `Golos Text`, связан с существующими цветовыми токенами FORUM и содержит обязательную навигационную, контактную и юридическую информацию без дефектов компоновки.
