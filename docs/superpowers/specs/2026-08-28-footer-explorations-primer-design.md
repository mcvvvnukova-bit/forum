# Пять вариантов подвала АСТ «Форум» на Primer

Дата: 2026-08-28  
Статус: согласовано для реализации

## Цель

Создать в Figma-файле `WT2IPB0eHD9ULCPENEktwp` пять визуально различимых вариантов подвала лендинга АСТ «Форум». Все варианты должны использовать Primer как единственную компонентную систему и коллекцию переменных `Forum` только в режиме `Light`.

## Исходное состояние

- Рабочая страница Figma: `Landing page`, узел `0:1`.
- Текущий лендинг: `7:3940`, ширина 1440 px.
- Текущий подвал: `133:5020`, ширина 1248 px.
- Внутри текущего подвала находится связанный инстанс официального `Primer Web (Community) / Footer`: component-set key `ecbd4c9b2adb690db9fc4baab925ba5c7915b4a9`.
- Доступны варианты `isCompact?=off` и `isCompact?=on`.
- В файле подключена библиотека `Primer Web (Community)` и доступны официальные Primer-компоненты `Footer`, `Link`, `Button` и `Heading`.
- Локально доступны компонент логотипа `Brand / Logo / Horizontal / Color` и component set `Primer / АСТ «Форум» Typography`.
- Коллекция `Forum` содержит только режим `Light`; тёмные или системные режимы не создаются.
- Продуктовая типографика: `Unbounded` для акцидентных заголовков и `Golos Text` для основного текста.

## Выбранный подход

Текущий подвал лендинга остаётся без изменений. Справа от существующего контента создаётся отдельная секция `Footer explorations / Primer`, содержащая пять самостоятельных фреймов шириной 1248 px. Фреймы размещаются вертикально с достаточным интервалом для сравнения и не встраиваются в лендинг.

Каждый вариант содержит связанный инстанс официального Primer Footer. Primer Link и Button применяются там, где соответствуют семантической роли. Повторяющиеся брендовые элементы собираются из существующих локальных компонентов, уже основанных на принятой композиции Primer. Новая библиотека примитивов и новый локальный компонент подвала не создаются.

## Общий контент

Во всех вариантах сохраняется один и тот же подтверждённый набор:

- `АСТ «Форум»`;
- `Платформа для участников строительства`;
- `О платформе`;
- `Для заказчиков`;
- `Для исполнителей`;
- `Контакты`;
- `© 2026 АСТ «Форум»`;
- `Согласие на обработку персональных данных`;
- `Политика конфиденциальности`.

Телефон, email, ИНН и полное название организации не добавляются без достоверного источника.

## Варианты

### 01 — Минимальный

Развитие текущей композиции: бренд и слоган слева, одна горизонтальная строка навигации справа, юридическая строка снизу. Используется `Footer` с `isCompact?=off`. Вариант показывает наиболее спокойное и нейтральное решение.

### 02 — Навигационный

Брендовая зона слева, справа две компактные колонки ссылок: «Платформа» и «Участникам». Юридическая строка остаётся в официальном Primer Footer. Основная задача варианта — повысить сканируемость и подготовить структуру к расширению навигации.

### 03 — CTA

Верхний ряд содержит бренд, короткий призыв к началу работы и официальный Primer Button с текстом `Зарегистрироваться`. Навигация располагается вторым уровнем, юридическая строка — в Primer Footer. Акцентная заливка и текст кнопки связываются с семантическими токенами `Forum / Light`.

### 04 — По аудиториям

Подвал организован вокруг двух групп: «Заказчикам» и «Исполнителям». Каждая группа содержит релевантную ссылку верхнего уровня; общие ссылки и контакты вынесены в отдельную компактную группу. Вариант предназначен для продуктового лендинга с двумя основными аудиториями.

### 05 — Компактный центрированный

Центрированная брендовая композиция с короткой строкой навигации и вариантом Primer Footer `isCompact?=on`. Этот вариант имеет минимальную визуальную высоту и демонстрирует направление для узких экранов без создания отдельного мобильного макета.

## Компоненты и токены

### Компоненты

- `Primer Web (Community) / Footer` — обязательный связанный инстанс в каждом варианте.
- `Primer Web (Community) / Link` — навигационные и юридические ссылки, если структура компонента позволяет применить нужный текст без отсоединения.
- `Primer Web (Community) / Button` — CTA в варианте 03.
- `Brand / Logo / Horizontal / Color` — логотип там, где он помещается без нарушения композиции.
- `Primer / АСТ «Форум» Typography` или существующие стили `FORUM` — брендовый и служебный текст.

Если официальные Link или Button не позволяют безопасно применить брендовый текст или типографику через штатные свойства, используется ближайшая связанная Primer-композиция без отсоединения. Создание нового примитива запрещено.

### Переменные `Forum / Light`

- фон: `color/bg/default`, `color/bg/muted` или `color/bg/subtle` по семантической роли;
- основной текст: `color/text/primary` или `color/text/heading`;
- вторичный текст: `color/text/secondary`;
- ссылки: `color/text/link`;
- CTA: `color/bg/accent`, `color/text/on-accent`;
- границы и разделители: `color/border/default`;
- интервалы: `spacing/xs`, `spacing/sm`, `spacing/md`, `spacing/lg`, `spacing/xl`.

Не допускаются жёстко заданные цвета, параллельные токены или режимы кроме `Light`. Если подходящей семантической переменной нет, сохраняется Primer Light fallback и это отмечается в итоговом отчёте.

## Компоновка

- ширина каждого варианта: 1248 px;
- высота определяется содержимым через Auto Layout;
- внутренние контейнеры используют Auto Layout, а не абсолютное позиционирование;
- варианты размещаются вертикально в секции с отдельными названиями;
- текущий лендинг и подвал `133:5020` не изменяются;
- фреймы не должны выглядеть как плавающие карточки без смысловой причины;
- длинные юридические ссылки переносятся без обрезки.

## Адаптивность и состояния

- Варианты проектируются на десктопную ширину 1248 px.
- Вариант 05 фиксирует компактный паттерн для последующей адаптации к узким экранам; отдельный мобильный фрейм в текущий объём не входит.
- Link и Button остаются связанными с Primer, поэтому их hover, focus, active и disabled состояния определяются библиотечными вариантами.
- В описании каждого exploration-фрейма фиксируется рекомендуемый порядок перестроения на планшете и мобильном: горизонтальные группы переходят в вертикальные, юридические ссылки получают перенос.

## Доступность

- порядок чтения: бренд → навигация или CTA → контакты → юридическая информация;
- текст и интерактивные элементы должны сохранять достаточный контраст в `Forum / Light`;
- названия ссылок остаются понятными без визуального контекста;
- CTA представлен только Button, навигация — Link;
- длинные строки не обрезаются, текстовые блоки имеют предсказуемую ширину;
- фокус и интерактивные состояния наследуются от Primer-компонентов и не заменяются локальными имитациями.

## Проверка результата

1. Структура:
   - создана одна секция и ровно пять именованных вариантов;
   - каждый вариант содержит связанный инстанс официального Primer Footer;
   - Primer Link и Button, где применимы, остаются инстансами библиотечных компонентов;
   - текущий подвал `133:5020` не изменён.
2. Токены:
   - коллекция `Forum`, режим `Light`, применена явно;
   - цвета и интервалы связаны с переменными;
   - новые коллекции и несистемные цвета отсутствуют.
3. Контент:
   - подтверждённые строки присутствуют без дубликатов;
   - вымышленные контакты и реквизиты отсутствуют.
4. Визуальная проверка:
   - нет обрезанного текста, наложений, текстовых «нитей» и пустых placeholder-слоёв;
   - варианты заметно различаются структурой, но выглядят частью одного продукта;
   - шрифты соответствуют `Unbounded` и `Golos Text` либо управляются связанным Primer-компонентом и отмечены как библиотечный fallback.
5. Ограничения:
   - отдельные библиотеки Primer Primitives и Octicons не отображаются как подключённые к файлу; новые иконки в вариантах не требуются;
   - состояния и полноценные mobile/tablet макеты специфицируются, но не создаются в текущем объёме.

## Критерий готовности

На странице `Landing page` создана отдельная область сравнения из пяти визуально разных, редактируемых и токенизированных подвалов. Все варианты используют Primer как единственную компонентную систему, `Forum / Light` как единственный брендовый режим, не изменяют действующий лендинг и проходят структурную и визуальную проверку.
