# Outline: локальная авторизация через Mailpit

Дата: 2026-08-20

## Цель

Заменить Google OAuth в локальном стенде Outline на вход по email magic link,
доставляемый в локальный Mailpit. Решение предназначено только для проверки
Outline на одном Mac и не отправляет письма в интернет.

## Архитектура

- Outline продолжает работать в Docker Compose за локальным HTTPS-прокси Caddy
  по адресу `https://localhost:3000`.
- Добавляется контейнер `axllent/mailpit:v1.30`.
- Outline отправляет письма на внутренний адрес `mailpit:1025` без TLS и
  SMTP-аутентификации. Этот порт не публикуется на хосте.
- Веб-интерфейс Mailpit публикуется только на
  `127.0.0.1:8025` и открывается по адресу `http://localhost:8025`.
- Письма хранятся только в контейнере Mailpit и могут исчезнуть после его
  пересоздания. Постоянный Docker volume не используется.

## Изменения конфигурации

1. Удалить `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` из окружения Outline,
   локального `.env` и `.env.example`.
2. Добавить SMTP-параметры Outline:
   - `SMTP_HOST=mailpit`;
   - `SMTP_PORT=1025`;
   - `SMTP_SECURE=false`;
   - `SMTP_FROM_EMAIL=Outline Local <outline@local.test>`;
   - `SMTP_REPLY_EMAIL=outline@local.test`.
3. Добавить сервис Mailpit без публикации SMTP-порта и без постоянного тома.
4. Обновить README: описать email-вход, адрес Mailpit и команды проверки.
5. OAuth-клиент Google Cloud не удалять. После удаления переменных Outline не
   будет его использовать; удаление внешнего OAuth-клиента остаётся отдельным
   необязательным действием.

## Пользовательский поток

1. Пользователь открывает `https://localhost:3000`.
2. Вводит любой тестовый email в форму входа.
3. Outline отправляет magic link через SMTP в Mailpit.
4. Пользователь открывает `http://localhost:8025`.
5. Открывает последнее письмо Outline и переходит по ссылке.
6. Outline создаёт рабочее пространство при первом входе либо открывает
   существующее при последующих входах.

## Обработка ошибок

- Если Mailpit не запущен, Outline зарегистрирует ошибку отправки; контейнеры и
  логи проверяются через `docker compose ps` и `docker compose logs`.
- Старые magic link могут истечь или стать недействительными; пользователь
  запрашивает новое письмо.
- Если браузер не доверяет локальному сертификату Caddy, пользователь должен
  принять сертификат или установить локальный корневой сертификат в доверенные.
- Mailpit не используется для реальной доставки и не должен публиковаться во
  внешнюю сеть.

## Проверка и критерии приёмки

- `docker compose config --quiet` завершается успешно.
- Outline, PostgreSQL, Redis, Caddy и Mailpit запущены; сервисы с healthcheck
  становятся healthy.
- `https://localhost:3000` отвечает HTTP 200.
- `http://localhost:8025` отвечает HTTP 200 только через loopback-интерфейс.
- На странице входа Outline отсутствует кнопка Google и присутствует форма
  email-входа.
- После ввода тестового email письмо появляется в Mailpit.
- Magic link открывает Outline без ошибки авторизации.
- В локальном `.env` больше нет Google Client ID и Client Secret.

## Вне области работ

- Настройка реального SMTP-сервиса и доставка писем в интернет.
- Сохранение писем Mailpit после пересоздания контейнера.
- Удаление OAuth-клиента из Google Cloud Console.
- Подготовка стенда к публичной или производственной эксплуатации.
