## Компоновка

Вариант остаётся фреймом шириной 1248 px с вертикальным Auto Layout и высотой по содержимому.

### Верхняя зона

- Все элементы выравниваются по левому краю.
- Логотип «Форум» располагается первым.
- Регистрационная строка располагается под логотипом.
- Правая часть верхней зоны остаётся пустой; дополнительные логотипы не создаются.

### Разделитель

- Между верхней и нижней зонами сохраняется один горизонтальный разделитель.
- Цвет разделителя связан с семантической переменной `Forum / Light` для границы.

### Нижняя зона

- Строится горизонтальным Auto Layout с распределением `space-between`.
- Copyright располагается слева и выравнивается по верхнему краю.
- Четыре существующие юридические ссылки располагаются одной вертикальной колонкой справа в текущем порядке.
- Длинные ссылки не обрезаются и не пересекаются; высота определяется содержимым.

## Primer и Forum / Light

- Связанный инстанс `Primer Web (Community) / Footer` с component-set key `ecbd4c9b2adb690db9fc4baab925ba5c7915b4a9` остаётся прикреплённым.
- Для юридических ссылок сохраняется штатная структура Primer Footer или связанные Primer Link, уже находящиеся в варианте; отсоединение не допускается.
- Используется только коллекция `Forum` в режиме `Light`.
- Фон, основной и вторичный текст, ссылки, граница и интервалы остаются связанными с существующими семантическими переменными.
- Тёмная палитра референса не переносится: заимствуется только композиция.
- Типографика остаётся на существующих стилях FORUM и шрифтах `Unbounded` / `Golos Text`.

## Порядок чтения и адаптация

Порядок чтения слоёв: логотип → регистрационная строка → copyright → юридические ссылки.

На узкой ширине нижняя зона должна перестраиваться в вертикальный стек: copyright перед колонкой ссылок. Отдельный мобильный фрейм в текущую задачу не входит.
