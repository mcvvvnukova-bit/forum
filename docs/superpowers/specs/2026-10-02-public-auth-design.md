# PROJ-31: форма входа и регистрации публичной части

Основание: текущая редакция PUB.02.02 в Outline, updatedAt 2026-10-02T14:29:50.285Z; прочитана API под Кузьмина. Прямое поручение реализовать документ рассматривается как принятие дизайна. Старая локальная спецификация с типами участников и контекстом перехода не применяется.

Общий React-компонент Primer Light: login «Войти в аккаунт» / «Войти по Сбер ID» / «Нет аккаунта? Зарегистрироваться»; register «Создайте аккаунт» / «Зарегистрироваться через Сбер ID» / «Уже есть аккаунт? Войти». Только существующий IAM Сбер ID; intent=login либо intent=register&subject=individual. Поля цели, returnTo и персональные данные не передаются и не сохраняются.

Публичные страницы сейчас выпускаются независимыми пакетами в незавершённых ветках. Изолированный пакет deployment/public-auth загружается одинаковыми script/link на всех существующих HTML публичной части. Адаптер нормализует существующие ссылки входа/регистрации; capture-handler открывает Primer Dialog поверх страницы. Режим отражается в /login либо /register; обновление открывает тот же компонент самостоятельно. Переключение режима заменяет запись истории. Закрытие крестиком, Escape, фоном возвращает страницу, прокрутку и фокус. Прямая страница имеет возврат на главную. Старый resume script не включается на новых страницах авторизации; перед запуском IAM удаляется его устаревшее намерение.

Сессия проверяется через /api/auth/session с timeout 10 секунд; 401 означает гостя, невалидный 200, сеть и 5xx показывают ошибку с повтором. URL auth=success не является сессией. Существующий аккаунт отображается как проверенный; повторная регистрация не запускается автоматически. Ошибки соответствуют E01–E07; закрытый/конфликтный аккаунт предлагает поддержку без обхода через регистрацию. Запуск блокирует двойное нажатие. Отключённый Сбер ID отключает кнопку и предлагает повтор проверки/возврат.

Кнопка — Primer Button с официальным знаком Сбера (не логотипом Сбер ID), зелёными семантическими vendor-токенами и белой подписью. Крупная жирная подпись обеспечивает минимальный контраст 3:1 для large text. Нейтральные поверхности, фокус, типографика — Primer Light; новые Forum mappings не вводятся.

Публикация только dev.astforum.ru: добавить ресурсы, два самостоятельных HTML и обратимое включение компонента в текущие публичные HTML без пересборки/перезаписи их текущего контента. Сохранить backup до изменения и проверить sha256 через origin и HTTPS. Production, API, общий пароль и конфигурация сервера не изменяются. PR связывается OP#PROJ-31; требуется проверить вкладку GitHub.

Проверки: режимы, реальный IAM URL, классификация сессии/ошибок, прямые ссылки, переключение, закрытие/история/фокус, отсутствие сохранённой цели, блокировки; unit-test деплоймента на временных директориях с повторным включением и rollback. TypeScript, ESLint, Vitest, сборка, Primer validator; IAB на desktop/tablet/360 px и клавиатура. Реальная регистрация и создание аккаунта не входят в UI-проверку.
