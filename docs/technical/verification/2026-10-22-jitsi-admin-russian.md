## Изменения

В штатный каталог `translations/custom` добавлен отдельный русский XLIFF с семью переопределениями. Исходный каталог поставщика, шаблоны, JavaScript и значения статусов не изменены.

| Исходная надпись | Перевод |
| --- | --- |
| Planen | Запланировать |
| Online | В сети |
| Abwesend | Нет на месте |
| Offline | Не в сети |
| In einem Meeting | На встрече |
| Meine Vertreter | Мои заместители |
| Meetling pro tip | Совет Meetling |

Файл подключён read-only в app и worker через Compose. Пересозданы только эти два сервиса командой `docker compose up -d --no-deps --wait --wait-timeout 150 app worker`; оба стали healthy. Сервисы Jitsi, база, Keycloak и WebSocket этой командой не пересоздаются.

## Подтверждения

- До изменения воспроизведены исходные надписи в открытом кабинете. Проверены точные ключи и штатный приоритет `translations/custom` по исходникам установленного Jitsi Admin 1.5.20.
- Symfony `lint:xliff` для именованного файла прошёл; `debug:translation ru --domain=messages` показал все семь русских значений из работающего приложения.
- После пересоздания контейнеров во встроенном браузере под Organizer VKS проверены кнопка «Запланировать», четыре пункта меню статусов, заголовок «Мои заместители» в профиле и «Совет Meetling». Действительные статусы пользователя не переключались.
- Пять публичных HTTP-проверок прошли: существующая главная Jitsi, OIDC issuer, ресурсы панели, вход под `/admin`, отклонение постороннего OAuth state.
- Read-only mount каталога проверен в обоих контейнерах; SHA-256 совпал с файлом в ветке.
- GitNexus не содержит актуального индекса этой ветки и каталога upstream: проверка выполнена по исходникам и работающей конфигурации. Результат `detect_changes` учитывается только как инвентаризация файлов.

Изменение ограничено текстами. Полную локализацию остальных экранов, изменение прав доступа и функциональности оно не включает.
