# Палитра цветов

Расширенная палитра для проекта «АСТ Форум». Основа — фирменные цвета из брендбука, дополненные промежуточными оттенками для UI-разработки.

## Фирменные цвета (из брендбука)

| Название | HEX | Роль |
|----------|-----|------|
| Primary Black | `#0A0A0A` | Основной чёрный, заголовки, основной текст |
| Secondary Dark | `#282828` | Тёмно-серый, фоны карточек, вторичный текст |
| Secondary Gray | `#4A4A4A` | Средне-серый, бордеры, иконки |
| Primary Orange | `#FF551A` | Основной акцент, CTA-кнопки, ссылки |
| Secondary Orange | `#FF7A4A` | Светло-оранжевый, hover-состояния |
| Tertiary Orange | `#FF9D66` | Ещё светлее, фоны, бейджи |

## Правила использования

- **Основной текст** — `#282828` (на белом фоне)
- **Заголовки** — `#0A0A0A`
- **Вторичный текст** — `#4A4A4A`
- **Акцентные элементы** (кнопки, ссылки) — `#FF551A`
- **Hover акцента** — `#FF7A4A`
- **Бордеры** — `#4A4A4A` / `#7A7A7A`
- **Фон карточек** — `#282828` (тёмная тема) / `#FFFFFF` (светлая)
- **Disabled / placeholder** — `#7A7A7A`
