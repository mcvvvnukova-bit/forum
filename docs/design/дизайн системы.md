# Дизайн-системы

Список публичных и open-source дизайн-систем, UI-библиотек и компонентных наборов, которые можно использовать как референсы для проектирования интерфейсов.

## Выбранные дизайн-системы

Для проекта выбрана дизайн-система - **Primer** [primer.style](https://primer.style/), компоненты для Figma - https://primer.style/product/components/
