# Архив уникальных исходников staging на VPS

Сохранены 1 октября 2026 года. Исходники, уже представленные опубликованной историей Git, повторно не копировались. Одинаковые файлы сохранены один раз; source-manifest.json сопоставляет исходные пути с архивом. Это предыдущие версии и разовые инструменты; их не следует запускать как действующий deploy. Архивные тесты не входят в проверки текущего приложения. Приватные настройки, базы, сборки и секреты исключены.
