# Исторические скрипты публикации

Сохранены с VPS при сверке 1 октября 2026 года. Скрипты привязаны к путям, контрольным суммам и версиям соответствующей публикации. Это исторические исходники, их нельзя запускать как команду развёртывания текущей версии. Действующий API на момент сверки: `20261001-sber-dns`; текущие исходники совпадают с `apps/api`.
