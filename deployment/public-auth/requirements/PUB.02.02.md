## Описание

Посетитель на одной из [страниц](/doc/pub0101-glavnaya-stranica-i-scenarii-raboty-nL3XeqEBBB) выполняет действие:

* начать работу
* войти

Система открывает всплывающее окно с вариантами регистрации и входа в Систему. Дальнейший процесс регистрации и авторизации описан в модуле [IAM: Авторизация и ролевая модель](/doc/iam-avtorizaciya-i-rolevaya-model-YAc0KlTSBn) .

## Требования к реализации

### Общие требования к формам

Общий компонент перехода на [всех страницах публичной части](/doc/pub0101-glavnaya-stranica-i-scenarii-raboty-nL3XeqEBBB).

При открытии с публичной страницы он показывается в модальном окне поверх страницы. Прямые URL /register и /login открывают тот же компонент как самостоятельную страницу. Это обеспечивает обновление, закладку и переход по ссылке без зависимости от открытого окна.

+++++++
### Вход

URL: /login

**Заголовок:** «Войти в аккаунт».

**Кнопки:**

* «Войти по Сбер ID»

Внизу: «Нет аккаунта? [Зарегистрироваться](https://docs.astforum.ru/doc/pub0202-perehod-k-registracii-i-vhodu-dC0gjF8wo8#h-registraciya)».

+++++++
+++++
### Регистрация

URL: /register

**Заголовок**: «Создайте аккаунт».

Кнопка «Зарегистрироваться через Сбер ID».

Внизу: «Уже есть аккаунт? Войти».

+++++
+++++++
### Закрытие и навигация

Модальное окно закрывается:

* крестиком «Закрыть окно»
* нажатием кнопки Escape
* нажатием на область на странице браузера за пределами модального окна.

Обновление /register или /login открывает экран соответствующего режима. Исходная страница и действие, с которого пользователь начал регистрацию или вход, не сохраняются.

## Обработка ошибок

Ошибка не запускает автоматическую новую попытку провайдера. «Повторить» доступно после возврата/завершения предыдущей попытки и создаёт новую серверную попытку. Ни код, ни внешний error_description не выводятся пользователю как HTML.

| Код сценария | Условие возникновения \| Текст сообщения | Действия |
|--------------|-----------------------------------------|----------|
| PUB.02.02-E01 | «Вы отменили подтверждение. Можно попробовать ещё раз» | Повторить / другой способ / вернуться. IAM не создаёт аккаунт. |
| PUB.02.02-E02 | «Регистрация через Сбер ID пока недоступна»  | Кнопка этого способа недоступна; вернуться / демо. Другой способ предлагается только для совместимого типа. |
| PUB.02.02-E03 | «Не удалось проверить вход. Повторите попытку» | Повторить / вернуться; никаких выводов об отсутствии аккаунта. |
| PUB.02.02-E04 | «Время ожидания входа истекло. Повторите вход ещё раз» | Повторить. Сессия не выдаётся по устаревшему callback. |
| PUB.02.02-E05 | «Доступ к аккаунту закрыт. Обратитесь в тех. поддержку» | Поддержка / вернуться; повторная регистрация для обхода не предлагается. |
| PUB.02.02-E06 | «Не удалось связать данные с аккаунтом. Обратитесь в тех. поддержку» | Поддержка / вернуться; не показываются чужие идентификаторы. |
| PUB.02.02-E07 | «Не удалось завершить вход. Попробуйте ещё раз» | Повторить / вернуться; безопасный код для диагностики, без технических деталей в интерфейсе. |
