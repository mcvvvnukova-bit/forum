# Локальная главная PUB.01.01.01 — план

**Goal:** отдельная локальная главная по текущему Outline, только Primer без Forum CSS.

**Architecture:** изолированный React/Vite-пакет и отдельная локальная Git-ветка. Общие Header/Footer, данные дословного контента, HomePage, единый Dialog записи. Сервер слушает только 127.0.0.1:5188. Публикация и удалённые изменения запрещены прямым указанием пользователя.

**Tech Stack:** React 19.2.8, Primer React 38.37.0, Primitives 11.10.0, Octicons 19.33.0, Vite 8.2.2.

## Источники и ограничения

- Главная: https://docs.astforum.ru/doc/pub010101-stranica-o-platforme-glavnaya-8RLs4d4lgh — прочитана 01.10.2026; PROJ-144 проверен в OpenProject.
- Демо: https://docs.astforum.ru/doc/pub020101-zapis-na-demo-posetitelem-8aPVHh6x0p — точный заголовок, подзаголовок и CTA.
- Порядок: Навигация → Hero → выбор цели → показатели → правила → демо → Нам доверяют → FAQ → подвал.
- Не использовать устаревшую локальную редакцию PUB.01.01.01: в ней другой порядок и переход «Начать работу».
- Только штатные Primer Light, семантические CSS-токены и Octicons. Forum CSS, шрифты, переопределение компонентов, сторонняя UI-библиотека исключены. Фирменный логотип и предоставленные логотипы партнёров — изображения, не тема.
- Реальные записи и авторизация не выполняются при проверках. Последующие лендинги и backend не относятся к этой главной; адреса переходов задаются отдельной конфигурацией.
