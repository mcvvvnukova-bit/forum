# Служебные исходники прошлых операций

Сохранены при сверке 1 октября 2026 года. Здесь находятся генераторы документов и диаграмм, сценарии восстановления и изменения планирования. Это архив исходников, а не автоматически выполняемые задания. Некоторые сценарии изменяют внешние приложения и требуют исходных приватных снимков, которые не публикуются в Git. Запускать только после проверки конкретного назначения и входных данных.
